# ⚖️ Advocate Website – Law Office Management System

A professional and responsive Advocate/Law Office website developed using **Core PHP, MySQL, HTML, CSS, Bootstrap, and JavaScript**. The project includes a dynamic frontend and an admin panel for managing website content.

## 🚀 Features

- Responsive Advocate/Law Office website
- Dynamic Hero Slider
- About Advocate section
- Services management
- Team/Advocate management
- Blog management
- Case Studies management
- Client consultation form
- Contact information management
- Admin Login & Authentication
- Admin Dashboard
- Dynamic content management using MySQL
- Image upload and management

## 🛠️ Technologies Used

- PHP (Core PHP)
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- MySQLi
- XAMPP

🎯 Purpose

The main purpose of this project is to develop a dynamic law office website where website content can be managed easily through an admin panel without manually editing frontend files.
